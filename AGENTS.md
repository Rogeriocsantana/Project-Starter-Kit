# Instruções do projeto

Antes de planejar ou implementar qualquer tarefa, leia integralmente:

`PREENCHA_PRIMEIRO.md`

`_project-kit/AGENTS_FULL.md`

O kit de planejamento está isolado em `_project-kit/`. O código do produto deve ser criado fora dessa pasta.

Quando o projeto ainda não tiver classificação de complexidade, consulte `COMO_AVALIAR_A_COMPLEXIDADE.md` antes de escolher o modo de trabalho.

Enquanto o projeto estiver em desenvolvimento, não exclua o kit. Quando todas as specs estiverem concluídas e as informações permanentes tiverem sido transferidas para a documentação do produto, o usuário poderá removê-lo.
