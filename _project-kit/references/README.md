# Referências — não usadas diretamente no produto

Coloque aqui materiais que ajudam os agentes a entender o resultado desejado.

- `_project-kit/references/images/`: screenshots, inspiração, wireframes e exemplos.
- `_project-kit/references/design/`: arquivos ou exportações de Figma, Sketch, Adobe XD e similares.
- `_project-kit/references/research/`: pesquisas, documentos, concorrentes e conteúdo de apoio.

Para cada conjunto relevante, preencha `_project-kit/references/REFERENCE_INDEX.md`. Não presuma que uma referência deve ser copiada literalmente; registre quais aspectos devem ser aproveitados.
