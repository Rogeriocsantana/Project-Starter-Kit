# Glossário do domínio

> Documento opcional e recomendado para domínios com termos ambíguos, regras
> críticas ou múltiplos atores. Discussões nascem em specs; somente definições
> aprovadas são promovidas a canônicas aqui.

## Como registrar uma entrada

```markdown
## Termo

- Estado: proposed
- Aprovado em: —
- Aprovado por: —
- Origem: SPEC-NNN
- Substitui: nenhum
- Substituído por: nenhum

Definição objetiva.

Não representa:

- conceito que costuma ser confundido com este termo.

Relaciona-se com:

- outro conceito e natureza da relação.
```

Estados permitidos:

- `draft`;
- `proposed`;
- `canonical`;
- `deprecated`.

Não use o glossário para inventar conceitos durante a implementação. Se uma
definição estiver ausente ou ambígua, registre a dúvida na spec ou em
`OPEN_QUESTIONS.md` antes de promover conhecimento.
