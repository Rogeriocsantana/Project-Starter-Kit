# Inventário de Interface

> Separe aparência, integração e comportamento real. Uma captura não prova que
> uma tela está conectada à API ou autorizada corretamente.

## Estados permitidos

- `concept`: ideia sem compromisso de implementação;
- `visual_preview`: composição visual isolada;
- `visual_approved`: direção aprovada, ainda não necessariamente integrada;
- `partially_integrated`: parte dos dados ou ações é real;
- `functional`: contratos e ações principais integrados;
- `validated`: funcionalidade, autorização, estados e UI Review aprovados;
- `superseded`: substituída e preservada para rastreabilidade.
