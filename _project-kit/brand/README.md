# Marca — material de direcionamento

Coloque nesta pasta logos, ícones, fontes, paleta, manual de marca e imagens institucionais.

Estes arquivos não devem ser usados automaticamente no produto. Antes do uso:

1. confirme licença e versão correta;
2. selecione o formato adequado;
3. otimize o arquivo;
4. copie o asset aprovado para a pasta de assets do produto;
5. registre origem e uso em `_project-kit/brand/ASSET_INDEX.md`.
