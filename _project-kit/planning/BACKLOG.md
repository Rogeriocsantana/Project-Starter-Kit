## Regras de promoção

Um item só sai do backlog para execução quando:

1. estiver coerente com o escopo e a baseline;
2. possuir requisitos e critérios de aceite suficientes;
3. estiver ligado a uma funcionalidade do `FEATURE_MAP.md`;
4. virar uma spec registrada em `specs/INDEX.md`;
5. cumprir todos os gates para alcançar `ready`.
