# Mídia de demonstração

`project-starter-kit-demo.gif` apresenta um cenário fictício do fluxo do kit. Todos os frames possuem o selo `DADOS FICTÍCIOS` para evitar confusão com métricas reais.

Para gerar novamente:

```powershell
python _project-kit/scripts/generate-demo-gif.py
```

O regenerador exige Python 3 e Pillow. O GIF já versionado pode ser usado no README e no GitHub Pages sem instalar essas ferramentas.
