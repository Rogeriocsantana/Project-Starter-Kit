# Documentação visual

Esta área guarda artefatos produzidos durante o planejamento e a execução:

- `diagrams/`: diagramas de arquitetura, dados e componentes;
- `flows/`: fluxos de usuário, estados e processos;
- `wireframes/`: wireframes produzidos para o projeto.
- `media/`: GIFs, vídeos curtos e outras mídias explicativas produzidas para a documentação.

Referências externas fornecidas pelo usuário continuam em `_project-kit/references/`. Um material de referência só deve ser promovido para esta pasta quando se tornar documentação do próprio projeto.

Registre nome, finalidade, origem, versão ou data e documentos relacionados em cada artefato. Diagramas não substituem contratos, ADRs ou critérios de aceite.
