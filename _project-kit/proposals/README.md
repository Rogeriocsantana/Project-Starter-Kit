# Propostas de evolução do Starter Kit

Este diretório preserva melhorias candidatas da metodologia. Uma proposta
registrada não é uma regra aprovada.

Use `_TEMPLATE.md`, atribua o próximo identificador `P-NNN` e adicione a proposta
ao `INDEX.md`.

As propostas pertencem ao repositório-fonte do Starter Kit. Projetos
instanciados registram apenas a evidência local e a referência à proposta,
evitando misturar o backlog do produto com o backlog da metodologia.
