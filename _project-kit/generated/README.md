# Visões geradas

Esta pasta contém artefatos descartáveis produzidos a partir das fontes de verdade do Project Starter Kit.

```bash
node _project-kit/scripts/generate-project-views.mjs
node _project-kit/scripts/generate-project-views.mjs --check
```

Opcionalmente, informe outro diretório `_project-kit` como argumento para validar uma cópia ou fixture.

O gerador produz dashboard, timeline, dependências, matriz de rastreabilidade, release notes e histórico de contribuições. Não edite essas visões manualmente; corrija a fonte e gere novamente.
